# UI redesign — version 2.0.0

## Direction

Version 2.0 replaces the previous card-and-list interface with a modern museum-atlas system designed around three ideas: immersive cartography, editorial discovery, and a calm premium mobile experience.

## Rebuilt surfaces

- Application shell, header, and bottom navigation
- Province browse and search experience
- Map mode and era/division controls
- Territory bottom dossier and its expanded research view
- Saved collection
- Telegram profile dashboard
- Settings and language selection
- Global search overlay
- Leaflet labels, tooltips, map controls, and dark-map treatment

## Visual system

- Near-black aubergine dark mode and warm mineral light mode
- Burgundy gradient as the primary action language
- Antique gold for archival numbering and heritage emphasis
- Translucent glass surfaces with restrained borders
- 15–30 px mobile corner radius scale
- Compact uppercase metadata and large editorial headings
- Floating controls instead of full-width toolbars where possible

## Preserved behavior

The redesign does not remove existing application logic. React Router routes, multilingual content, Telegram safe areas and haptics, saved/visited state, map modes, GeoJSON geometry, territory measurements, live settlement loading, profile data, and settings persistence remain connected.
