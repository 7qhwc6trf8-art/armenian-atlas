# Elegant UI — version 2.1.0

## Design direction

Version 2.1 turns the mobile atlas into a quieter editorial product inspired by archival folios, museum catalogues, antique cartography, and modern iOS interfaces. The redesign avoids oversized gradients and crowded card grids in favor of strong hierarchy, controlled spacing, fine borders, archival numbering, and restrained burgundy/gold emphasis.

## Rebuilt surfaces

- Application shell with subtle paper-grid texture and refined device framing
- Header, emblem, search and saved actions
- Floating bottom navigation with compact active icon treatment
- Map mode command bar, era/division filters, map controls, labels, and dossier
- Province directory with featured territory and single-column folio cards
- Saved collection with archival collection header and dossier cards
- Profile dashboard with exploration progress, statistics, actions, and recent provinces
- Settings page with folio header, theme selector, language matrix, grouped switches, and data tools
- Full-screen search sheet with structured province and settlement results

## Visual system

- Warm mineral ivory light mode
- Near-black aubergine dark mode
- Oxblood burgundy primary actions
- Antique gold numbering and heritage accents
- Fine hairlines and subtle inset borders
- 14–31 px radius scale optimized for mobile
- Editorial headings with compact uppercase metadata
- Glass effects limited to floating controls and navigation
- Safe-area aware controls for Telegram Mini Apps and modern iPhones

## Preserved functionality

React Router routes, five languages, Telegram user data and haptics, saved and visited state, OpenStreetMap/Leaflet behavior, GeoJSON province and division layers, settlement filters, territory measurements, profile progress, search, settings persistence, and Vercel SPA routing remain connected.
